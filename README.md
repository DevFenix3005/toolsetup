# ✨ Robert-tan's Sugoi Terminal Setup ✨

Welcome to my personal dotfiles setup script! This script automates the installation of aesthetic and productive CLI tools that I love to use on a fresh Ubuntu installation 🐧💻✨

## 💾 What's Included

| Tool | Description |
|------|-------------|
| `neofetch` | System info with ASCII art |
| `bat` | Prettier `cat` with syntax highlighting |
| `htop` | Interactive process viewer |
| `btop` | Modern `htop` with animations |
| `eza` | Enhanced `ls` with icons |
| `fzf` | Fuzzy finder for terminal |
| `ripgrep` | Fast file search |
| `tldr` | Simplified man pages |
| `fortune`, `cowsay`, `lolcat` | Fun + fortune + rainbow terminal magic |
| `starship` | Prompt customizer |
| `zoxide` | Smarter `cd` replacement |
| `fd` | Simple and fast alternative to `find` |
| `duf` | Disk usage with visuals |

## 🛠️ Installation

1. First install oh-my-zsh!
```bash
sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"
```

2. Clone the repository:
```bash
git clone https://github.com/DevFenix3005/toolsetup
cd toolsetup
```

3. Make the script executable:
```bash
chmod +x tools.sh
```

4. Run the script:
```bash
./tools.sh
```

4. Restart your terminal or source your `.zshrc`:
```bash
source ~/.zshrc
```
